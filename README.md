# 🌐 AirBnb-for-campers Backend

This is the **ASP.NET Core Web API** backend for the AirBnb-for-campers project. It provides the RESTful API required by the frontend application to manage camping spots, user login, bookings, and more.

---

## 🛠️ Tech Stack

- **ASP.NET Core** (.NET 6 or later)
- **C#**
- **Entity Framework Core**
- **MySQL Server**
- 
## 📦 Features

- User Registration
- Camping spot management
- Booking management
- User profile management
- Separate endpoints for owners and users
- RESTful API following best practices

## 🏁 Getting Started

### Prerequisites

- [.NET 6 SDK](https://dotnet.microsoft.com/en-us/download) or later
- SQL Server or other configured database
- A tool like [Swagger or Postman](https://www.postman.com/) for API testing (optional)
- The [airbnb-frontend-finale3]([https://github.com/your-frontend-repository-link](https://github.com/rexmainimo/airbnb-frontend-finale3) running for full functionality

---

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/your-github-username/AirBnb-for-campers.git

# Navigate to the project directory
cd AirBnb-for-campers

# Restore dependencies
dotnet restore

# Run the application
dotnet run

# By default, the API will be accessible at:
http://localhost:5156
